# F04 — Spec

A vitrine oferece o checkout com formulário HTML protegido por CSRF para participantes autenticados. O POST consome o serviço compartilhado de compras e redireciona para Meus ingressos quando a reserva é aceita. A consulta de ingressos usa o ID da sessão e exibe o evento, o rótulo do status e o código. O PRD define os critérios X14 e X34.
